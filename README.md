# ☕ Flappuccino

A fast-paced arcade game built with Python & Pygame, inspired by [PolyMars](https://polymars.itch.io/).

---

## 🎮 About

Flappuccino is a coffee-themed arcade game where you dodge sugar cubes and collect coffee beans to survive as long as possible. Inspired by a game jam project by PolyMars, this remake adds a new spin on the original game loop — including a character selection system, a power-up mechanic, and a full co-op mode for two players.

---

## ✨ Features

- 🧋 **Character Selection** — Choose from multiple unique characters, each with their own power-up ability
- ⚡ **Power-Up System** — Fill your power-up bar by collecting coffee beans to unleash character-specific abilities:
  - **2x Coffee Beans** — doubles your bean collection rate
  - **Time Slow** — slows down all incoming objects
  - **Invincibility** — temporary immunity to sugar cube damage
- 👥 **Co-op Mode** — Play with a friend in split-screen, each managing their own lane
- 🏆 **High Score Tracking** — Your best score is saved locally between sessions
- ⏸️ **Pause Menu** — Pause mid-game and resume or quit at any time
- 📈 **Increasing Difficulty** — Object speed ramps up over time to keep you on your toes

## 🕹️ Controls

### Single Player
| Action | Key |
|--------|-----|
| Jump / Move Up | `W` |
| Move Left | `A` |
| Move Right | `D` |
| Pause | `ESC` |

### Co-op — Player 2
| Action | Key |
|--------|-----|
| Jump / Move Up | `↑` |
| Move Left | `←` |
| Move Right | `→` |

## 🚀 How to Run

### Requirements
- Python 3.x
- Pygame

### Install dependencies
```bash
pip install pygame
```

### Run the game
```bash
python game.py
```
